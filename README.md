Spartan Scholars Web App

To Use React and Spring Boot
- "npm install" in a terminal (I did it in Command Prompt while in the folder "react-frontend")
- Everytime you run the project you need to run from the backend and frontend.
- Run backend normally (It runs on http://localhost:8080)
- Run frontend in a terminal while in the folder (It runs on http://localhost:3000)
- The frontend does take a bit to start but it'll run and say something like "Compiled successfully!"
- With React, you only have to go on http://localhost:3000 and everything should be there
